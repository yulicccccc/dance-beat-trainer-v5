# Dance Beat Trainer — Project State

**Status:** ALPHA / ACTIVE DEVELOPMENT  
**Current release:** Foundation + Rhythm Practice Alpha  
**Deployment target:** `dance-beat-trainer-v5` Worker only

## Implemented

- Strict Practice/Review route and DOM isolation
- Local-first video import
- Full-width single practice player
- Dual review player layout
- Pan/zoom, fit, mirror, rotation
- Playback speed
- Manual BPM and count calibration
- Rolling beat rail
- Smart 1–4 / 5–8 / 1–8 loops
- Optional connection beats
- Count-in
- Phrase notes for Motion / Knowledge / Learning
- Continuous personal count recording alpha
- Review sync, offset, unified play/pause/rate

## Not yet implemented

- Automatic SmartBeat analysis and confidence
- Editable multi-segment Tempo Map
- Local beat-point editing and undo history
- Adaptive eighth/sixteenth subdivision
- Count-master automatic segmentation
- Non-destructive Punch-in mapping
- Count-track synchronization at variable rates
- Structured Motion Timeline editor
- Cross-project Knowledge system
- Delayed review and scaffold-fade engine
- Project library, IndexedDB media references, import/export
- Review coverage detection

## Release gate

Real iPhone Chrome remains the final acceptance environment. Desktop build/test success does not equal user approval.
